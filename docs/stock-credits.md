# 샘플 사진 크레딧 (didisam/img/stock)

홈페이지 템플릿의 분위기 사진으로만 쓰는 샘플 사진 목록이다. 목록 데이터는 `didisam/hpstock.js`(`window.HPSTOCK`)에 있다.

- 라이선스: 모두 **CC0 1.0 (Creative Commons Zero, 퍼블릭 도메인 기증)** 이다. 상업적 사용 · 수정 · 재배포가 허용되고 출처 표시 의무는 없지만, 아래에 작가와 원본 페이지를 기록한다.
- 출처 확인
  - Wikimedia Commons: 파일 페이지와 Commons API의 `LicenseShortName`(CC0)를 확인했다. 구조화 데이터의 저작권 라이선스(P275)가 CC0(Q6938433)인 파일만 검색해 골랐다. 이 가운데 상당수는 Unsplash · Pexels 등에서 작가가 CC0로 공개해 Commons로 옮겨진 사진이다(작가 칸 참고).
  - StockSnap.io: 사이트 전체가 CC0 라이선스인 무료 사진 사이트다. 라이선스 · 작가 · 원본 페이지는 Openverse API(WordPress 재단 운영, `license=cc0`) 기록으로 확인했다. StockSnap 원본 페이지는 봇 차단(Cloudflare)으로 이 환경에서 직접 열 수 없었으므로, 사람이 한 번 더 열어 보기를 권한다(목록의 via 칸이 StockSnap인 사진). 이 사진들은 공개 크기 한도로 긴 변이 960px이므로 카드 · 소개용으로만 쓴다(hero 슬롯 없음).
- 사용 원칙: 특정 강사 · 수강생 · 합격자 · 후기 · 시설 실물처럼 보이게 이름이나 캡션을 붙이지 않는다. 얼굴이 크게 나온 사진은 넣지 않았다(손 · 뒷모습 · 원거리 · 사물 · 공간 위주). 사진 속 상표 · 글자가 보이는 사진은 제외하거나 잘라 냈다.
- 처리: 긴 변 1600px(`<id>.webp`)과 800px(`<id>-800.webp`) 두 벌, WebP. 원본에서 크롭 · 축소만 했고 합성은 하지 않았다.

- 선정 기준: 얼굴을 식별할 수 없는 사진만 골랐다(손 · 뒷모습 · 원거리 · 흐림 · 측면 실루엣). 실제 특정 건물이 드러나는 사진, 상표 · 로고 · 읽히는 글자가 드러나는 사진은 제외했고, 책 제목 · 상표가 걸린 사진은 그 부분을 잘라 냈다(hum-04 · hum-28).
- 출처: 모두 Wikimedia Commons에서 구조화 데이터의 저작권 라이선스(P275)가 CC0(Q6938433)인 파일을 검색해 골랐다. 대부분 Unsplash 작가가 CC0로 공개해 Commons로 옮겨진 사진이다. 파일마다 Commons API의 `LicenseShortName`(CC0)과 파일 페이지의 CC0 1.0 링크(`publicdomain/zero/1.0`)를 직접 확인했다(아래 확인 칸).
