# 인가 · 규정 준수 기능(v30)

공개 규정 기준의 구현 기록입니다. 인가나 심사 통과를 보장하지 않으며, 심사 전에 심사기관과 공단에 현행 기준을 확인합니다.

## 근거(2026-11-06 확인)
- 사업주 직업능력개발훈련 지원규정, 고용노동부 고시 제2026-48호 별표 1, 제6조, 제11조, 제28조
- 국민내일배움카드 운영규정, 고시 제2026-39호 제19조, 제32조, 제34조, 제35조
- 제38조(수료 보고 10일), 제58조(자료 5년)는 제2023-68호 본문으로 확인했으며 현행 조문 대조가 필요합니다.
- 평생교육법 시행령 제48조, 제49조의2, 시행규칙 제17조, 제17조의2

## 유형별 기본값
| 유형 | 프로필 | 규칙 |
|---|---|---|
| 직업훈련원 | `moel-entrust` | 켜짐 |

| 평생교육원 | `lifelong` | 켜짐, 진도 · 본인확인 규칙 없음 |

## 구현과 미연동
| 항목 | 상태 |
|---|---|
| 동시접속 차단, 1일 학습시간 서버 판정, 활동 로그, QR 출결 코드 검증 | 서버 구현(Node · Java) |
| 차시 인정, 수료 판정, 수강평 관문, 무작위 출제 | 학습자 화면 구현. 판정 근거는 브라우저 기록을 포함 |
| 베낀 답안 확인 | 과제 본문의 3-gram 유사도, 운영자 최종 판정. 기준값은 기관 설정 |
| 휴대폰 인증, 공단 MOTP | 연동 지점만 구현. 제공사 없으면 501 `provider_missing` |
| 자동모니터링시스템, HRD-Net | 미연동. 데이터 내려받기까지만 구현 |
| 전용 배포 | `didisam/deploy/tenant.example.yaml` 경로 사용, 공유 SaaS 허용 여부는 심사기관 확인 |

## 알려진 위험
- 평가 정답이 게시본(`lsite.pub`)을 통해 학습자 브라우저로 전달되고 채점도 브라우저에서 이뤄집니다. 심사 전에 서버 채점으로 옮겨야 합니다.
- 차시 학습시간은 브라우저가 보낸 값(요청당 60초 이하, 1일 합계 서버 제한)입니다. 재생 사실 자체를 서버가 증명하지는 않습니다.
