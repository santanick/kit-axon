공개 규정 기준의 구현 기록입니다. 인가나 심사 통과를 보장하지 않으며, 심사 전에 심사기관과 공단에 현행 기준을 확인합니다.

## 서버 채점(v30.1)
- 규정이 켜진 고용노동부 프로필의 시험(`type: exam`)은 게시본에 문항과 정답을 싣지 않습니다.
- 응시 시작 때 서버가 출제 수만큼 무작위로 뽑아 문항만 내려 주고, 제출 시 서버가 채점합니다. 정답은 학습자에게 보내지 않습니다.
- 재시작해도 같은 응시와 종료 시각을 유지하고, 종료 후 60초가 지나면 답안을 인정하지 않습니다. 원본은 `cpl_exam`에 있습니다.
- 학습시간은 직전 기록 이후 실제 경과 시간(+5초)까지만 적립합니다.

## 알려진 위험
- 차시 학습시간은 경과 시간 내에서 제한하지만, 영상이 실제로 재생됐는지까지 서버가 증명하지는 않습니다.
- 퀴즈(`type: quiz`)와 영상 구간 퀴즈는 연습용으로 보고 브라우저 채점을 유지합니다. 심사기관이 평가로 본다면 서버 채점 대상에 포함해야 합니다.
- 수료 표시는 학습자 화면 계산이며, 운영자 화면의 수료 보고가 서버 채점 점수를 기준으로 합니다. 진도 원본(`prog.p`)의 서버 판정은 후속 과제입니다.
