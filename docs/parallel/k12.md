# 학원(초중고) 운영 CRM

학원조아 CRM의 기능 요건을 참고해 디디쌤 기능으로 구현합니다. 화면 구성과 문구는 옮기지 않습니다.

## 1단계 범위
- 원생: 재원 상태, 학교 · 학년, 복수 보호자, 형제 자동 연결, 수강 이력, 전반 · 휴원 · 퇴원 일괄 처리, CSV 등록 · 내보내기
- 출석부: 달력, 등 · 하원, 사유, 진도, 과제, 메모, 보강, 휴강, 출석 통계, 시간표
- 성적: 시험 종류, 점수 입력, 미응시, 공동 석차, 누적 그래프, 성적 알림 기록, CSV
- 상담: 신규 문의, 원생 전환, 재원 상담, 분류, 상담자, 미상담자
- 수납: 월별 일괄 발생, 정기 납부일 자동 발생, 차량비, 할인, 분납, 수납 취소, 미납 알림 기록, 통계
- 운영 현황: 일일 요약, 월별 재원 · 신규 · 퇴원, 강사별 지표

## 데이터
| 위치 | 내용 | 서버 암호화 |
|---|---|---|
| `members[].crm` | 원생 부가 정보 | JSON 전체 |
| `crmLeads` | 신규 문의 | 이름, 학교, 보호자, 연락처, 메모 |
| `crmHist` | 수강 이력 | 메모 |
| `classes[].crmDay` · `k12Exams` · `makeups` | 출결 부가 기록, 성적, 보강 | JSON 전체 |
| `consults`, `parents`, `msgs` | 기존 구조 사용 | 기존 대상 |

주소, 직장, 집전화, 사진은 받지 않습니다. 강사에게는 담당 수업과 원생의 재원 상태만 전달합니다.

## 연동 전 한계
- 알림은 메시지 기록으로 남습니다. 문자 · 알림톡 · 보호자 앱 전달은 업체 연동 후 시작합니다.
- `S.inbox` 본문은 항목 암호화 대상이 아닙니다.
- 강사 화면의 알림 기록은 서버에 저장되지 않으므로 성적 알림 버튼을 숨겼습니다.
- 정기 납부일 자동 발생은 운영자가 수납 화면을 열 때 실행합니다. 서버 예약 작업이 아닙니다.
- 일일 요약은 입력된 기록을 규칙으로 정리합니다. 외부 AI로 원생 정보를 보내지 않습니다.
- 분납 중인 청구는 보호자 온라인 결제 대상에서 빠지며, 현장에서 수납합니다.

## 2단계 후보
교재 재고 · 묶음, 다중 사업자, 인사서류, 키오스크, 영수증, 학부모 앱 화면.
