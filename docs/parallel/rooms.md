# 채팅방별 시작 지시문

## 통합 채팅방
```
kit-axon 저장소의 디디쌤 Ver2 통합 채팅방으로 작업합니다. 쓰기 권한 연결을 승인합니다.
CLAUDE.md를 먼저 읽고 규칙을 따르십시오. 열린 PR을 하나씩 점검·병합하고, 코어 변경 요청을 core/<주제> 브랜치에서 처리하십시오.
병합 시 ?v=와 sw.js 버전을 올리고, 병합 후 tests/ui/smoke.js와 실제 주소를 확인하십시오.
```

## 시나리오 채팅방
`<id>`와 요구사항만 바꿔 사용합니다.
```
kit-axon 저장소의 디디쌤 Ver2 시나리오 <id> 채팅방으로 작업합니다. 쓰기 권한 연결을 승인합니다.
CLAUDE.md를 먼저 읽고 규칙을 따르십시오. scenario/<id> 브랜치에서 scripts/scenarios.json에 등록된 파일만 수정하고, main에는 직접 push하지 마십시오.
코어 변경이 필요하면 PR 설명의 「코어 변경 요청」에 적으십시오.
요구사항: <기관·RFP·회의록·원하는 흐름>
```
