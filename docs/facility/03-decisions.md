# v40 결정 사항 (대표님 2026-11-14 00:07 「추천대로」)
1. 결제: 1차는 현장 결제 · 무료 · 승인제. 토스 서버 승인(confirm · 취소)은 같은 v40 안에서 이어서 붙이되, 상점 키는 GCP Secret(대표님 입력) — 키가 없으면 온라인 결제 버튼은 숨기고 '현장 결제'만 보인다.
2. 대학 구성원 확인: 학번 자기 입력 + 운영자 승인. 재학생 명단(학번 목록) 업로드 시 자동 대조. SSO는 후속.
3. 노쇼: 시작 15분 후 미입장 자동 취소, 3회 누적 시 30일 예약 정지 — 시설별 설정값.
4. 월이용권 환불: 미사용 = 구매액 − 구매액×10%(당일), 1~5회 = 구매액 − 일일권×5 − 구매액×10%, 6~10회 = 구매액 − 일일권×10 − 구매액×10%, 11회 이상 환불 없음(0 미만은 0). 수수료율 · 일일권 단가 · 구간은 시설별 설정값.
5. 개인정보 보관: 이름 · 연락처 1년, 차량번호 30일, 출입 기록 1년(설정값, 기관 개인정보 담당 확인 권고 문구 표시).
6. 하단 탭은 현재 앱(홈 · 일정 · 내 과정 · 나 + AI 튜터 버튼) 유지, 내 예약은 일정 탭, 홈 칩 「예약」, 홈 맨 위 「오늘 예약」 QR 카드.
