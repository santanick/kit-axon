# 고객군별 보안 인증 · 기준 로드맵 (체크리스트 15)

산타가 디디쌤 Ver2를 공공 · 대학 · 직업훈련 · 초중고 · 기업에 납품할 때 고객이 요구하는 보안 인증 · 기준을 고객군별로 정리하고, 현재 충족 수준 · 갭 · 일정을 관리합니다.

- 작성: 2026-11-24 · 보안 2차(수석 기획자). 근거: 「디디쌤 Ver2 AI 보안 · 가디언 통합 보고서」 Part 2(공공 · 교육 고객 요구), `docs/compliance/README.md`, `security/findings/seed.json`.
- 분기마다(1 · 4 · 7 · 10월 첫 주) 갱신합니다. 기준 원문 · 시행일은 바뀔 수 있으므로 표의 「확인 필요」 항목은 납품 전 원문으로 다시 확인합니다.
- 상태 표기: ● 충족 · ◐ 부분 · ○ 미흡

## 4. 대표님 결정 필요
1. 공공 SaaS 인증 경로: CSAP 간편등급 신청 여부(비용 · 기간) 또는 설치형 · N2SF 대응 우선.
2. 직업훈련 본인인증 제공사 선정(계약 전까지 `IDV_ENFORCE` 꺼짐 유지).
3. ISO 27001 · ISMS-P 자발 인증 시점.
