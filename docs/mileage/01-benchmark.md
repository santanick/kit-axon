# 01. 학습 마일리지 · 포인트 · 보상 벤치마크 (v42 R1)

작성: 2026-11-14 · 범위: 해외 · 국내 27개 사례 + 동기부여 연구 3건
표기 원칙: 원문에서 확인한 수치만 적고, 원문에 없거나 직접 읽지 못한 항목은 「미확인」으로 표시합니다. 수치는 각 출처의 게시 시점 기준입니다.

## 0. 요약

| 구분 | 핵심 발견 |
|---|---|
| 소비자 학습앱 | 「현금성 보상」은 거의 없고, XP · 연속 학습(스트릭) · 주간 리그 · 앱 내 화폐(젬)로 습관을 만듭니다. Duolingo는 스트릭 7일 도달 학습자의 코스 완료 가능성이 3.6배라고 공개했습니다. |
| 학교 · 교실 | 교사가 수동 부여하는 행동 포인트가 주류입니다. 공개 순위 · 감점 노출은 수치심 · 순응 중심이라는 비판이 큽니다. |
| 국내 대학 | 비교과 마일리지 → 장학금 전환이 표준입니다. 환산 방식은 ① 1점당 정액(예: 1점=1,000원, 1인 상한 20만 원) ② 등급별 정액(예: 50 · 30 · 20만 원, 인원 한정) ③ 포인트=원(1P=1원) 세 가지입니다. 최소 기준점 · 항목별 연간 한도 · 증빙 승인이 공통입니다. |
| 해외 대학 | 포인트를 돈으로 바꾸지 않고 「공식 비교과 기록(CCR)」과 검증 가능한 디지털 배지(Open Badges 3.0, Credly)로 남깁니다. |
| 기업 학습 | LXP 포인트는 「학습량 지표」(Degreed: 학습 1시간≈1점, 보상 아님)이거나 배지 포인트 → 코인 → 리워드 숍(Docebo)입니다. Deloitte는 주간 리셋 · 근접 10인 리더보드로 주간 재방문 37% 증가를 보고했습니다. |
| 학원 · 사교육 | 교사 칭찬 포인트 → 스토어(기프티콘 · 실물) 구조가 일반적입니다. 학원비 직접 차감 사례는 확인하지 못했고, 2026년에는 비용 부담으로 포인트 제도를 폐지 · 축소하는 사례(웅진씽크빅, 윤선생)가 나왔습니다. |
| 공공 · 평생 · 직훈 | 지자체 평생학습 포인트 → 지역 서점 교환권, 바우처형(평생교육이용권 35만 원, 내일배움카드 5년 300~500만 원)은 「기한 내 미사용 시 소멸」과 강한 부정수급 제재(최대 5배 반환)가 특징입니다. |
| 일반 로열티 | 유효기간(카드 60개월, Starbucks Green 6개월) · 선입선출 차감 · 소멸 6개월 전부터 매월 사전 고지 · 등급별 적립률 차등이 관행입니다. |

디디쌤 시사점: 「적립(무엇을 하면) · 한도 · 승인 · 소멸 · 보상 전환」을 분리된 규칙으로 두고, 기관 유형별로 기본값만 다르게 주는 정책 엔진이 사례 전부를 덮을 수 있습니다.
